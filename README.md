# README
# Modelio R&D on GitHub

Organization: [github.com/Modelio-R-D](https://github.com/Modelio-R-D) ("Modelio R&D team", Paris, linked to Softeam). 25 public repositories listed on 25 Nov 2026.

## 1. Overview

- **Modelio modules (Java, mostly GPL-3.0):** extensions for the Modelio modeling tool: attack trees, TOSCA, MARTE, CAMEL, UML Testing Profile, variability.
- **Automation and AI (Python, Apache-2.0):** scripts, recipes and a MODELS 2026 paper artifact on LLM-assisted modeling.
- **MYRTUS use cases (mostly HTML):** demo projects for smart traffic, healthcare and face-recognition apps.
- **Research and theses:** NLP4RE, ARQAN, COMER, RQCODE, food datasets.
